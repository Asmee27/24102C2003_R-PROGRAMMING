# NPTEL: Foundations of R Software – Practicals

Repository containing code implementations, lab exercises, and assignments for the NPTEL course **Foundations of R Software** (IIT Kanpur).

### 📌 Highlights
* **Core Topics:** Vectors, matrices, data frames, control flow (`apply` family), base graphics, and `ggplot2` and many more.
* **Prerequisites:** R (v4.0+) & RStudio.
* **Usage:** Clone repo, set directory using `setwd()`, and execute `.R` scripts.
